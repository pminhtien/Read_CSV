# CSV Desk

A lightweight, browser-based CSV viewer that lets you explore and analyze your data instantly. **No download required – use it directly online!**

## ✨ Features

- 📂 **Load CSV files** directly from your device or from a URL
- 🔍 **Search & filter** across all columns in real-time
- 📊 **Sort data** by clicking column headers
- 📄 **Paginate** through large datasets (25, 50, 100, or 250 rows per page)
- 🔒 **100% private** – All data stays in your browser, nothing is uploaded
- 🎯 **No installation needed** – Works in any modern web browser
- ⚡ **Fast & responsive** – Built with vanilla JavaScript and optimized performance

## 🎨 How to Use

1. **Load a file:**
   - Drag & drop a CSV file onto the interface
   - Click "Browse files" to select from your device
   - Paste a direct URL to load from the web

2. **Explore your data:**
   - Search across all columns using the search box
   - Click column headers to sort ascending/descending
   - Use pagination controls to navigate through rows

3. **Privacy:**
   - Your files never leave your browser
   - No data is sent to any server
   - Works offline after the initial load

## 🛠️ Built With

- **HTML5 & CSS3** – Clean, responsive interface
- **Vanilla JavaScript** – No framework bloat
- **[PapaParse](https://www.papaparse.com/)** – Robust CSV parsing
- **[Tabulator.js](http://tabulator.info/)** – Advanced table rendering
- **GitHub Pages** – Free, instant deployment

## 🔄 Supported CSV Formats

- Standard comma-separated values (CSV)
- Tab-separated values (TSV)
- Semicolon-separated values
- Pipe-separated values (auto-detected)
